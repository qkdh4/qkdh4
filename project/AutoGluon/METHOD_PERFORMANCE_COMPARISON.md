## 4. 왜 성능 차이가 발생했는가? (해석)

현재 결과만 보면 AutoGluon이 더 낮은 오차를 보이지 않았는데, 이는 아래 요인의 영향 가능성이 큼:

1. **검증 방식 차이 가능성**
   - XGBoost+LSTM: 기존 코드의 단일 검증 분할/재귀 예측 기반 지표
   - AutoGluon: 다중 검증 윈도우(num_val_windows=5) + 대규모 탐색
   - 동일한 데이터라도 검증 설계가 다르면 MAE/RMSE의 절대값이 크게 달라질 수 있음

2. **학습 시간 대비 탐색 공간 효율 문제**
   - AutoGluon은 313개 모델을 탐색했지만, 모든 모델이 충분히 수렴하지 않았을 수 있음
   - 탐색 폭이 큰 설정은 데이터 특성에 따라 과도한 분산을 유발할 수 있음

3. **단일 시계열(도시 1개) 조건에서의 모델 적합성**
   - 글로벌 딥러닝 계열 모델은 다중 아이템 시계열에서 장점이 크게 나타나는 경우가 많음
   - 단일 아이템에서는 트리/단순 통계 모델이 더 안정적인 경우가 빈번함

4. **목표 함수/예측평가 기준 차이**
   - AutoGluon 내부 최적화는 RMSE 기준, XGB/LSTM 파이프라인은 별도 학습·검증 로직
   - 내부 최적화 지표와 외부 비교 지표가 완전히 정렬되지 않으면 체감 성능 차이 발생

## 5. 결론

- **이번 실행 결과 기준 우위는 XGBoost+LSTM** 입니다.
- 다만 이는 모델 클래스의 절대 우열이라기보다, 현재 데이터/검증설계/튜닝전략 조합의 결과로 해석하는 것이 타당합니다.
- 공정 비교를 위해서는 동일한 백테스트 프로토콜(동일 horizon, 동일 split, 동일 평가함수)로 재실험이 필요합니다.
