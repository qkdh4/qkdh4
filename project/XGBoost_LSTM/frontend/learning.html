예측 대시보드

예측/이상치/보간 결과를 실제 화면과 함께 학습합니다.

1) 예측 분석

과거 AQI 패턴을 학습해 다음 기간 AQI를 추정합니다. 실제선과 예측선이 가까울수록 모델이 시계열 패턴을 잘 잡았다고 볼 수 있습니다.

체크 포인트

  • 급등/급락 구간에서 오차가 커지는지 확인
  • RMSE가 큰 경우 불확실성 밴드가 넓어짐

2) 이상치 탐지

Autoencoder와 Isolation Forest를 함께 사용해 비정상 구간을 탐지합니다. 두 모델이 동시에 탐지한 구간은 우선 점검 대상입니다.

체크 포인트

  • 이상도 점수 임계치 상회 구간 확인
  • 합의 이상치의 시점과 실제 AQI 급변 여부 대조

3) 결측치 보간

여러 보간 기법을 동일 데이터에서 비교하여 MAE/RMSE가 가장 낮은 방법을 선택합니다.

체크 포인트

  • 원본 대비 보간선의 패턴 보존 여부
  • 오차 막대그래프에서 과도한 방법 배제
