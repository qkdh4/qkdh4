# Face Note

로컬 카메라 또는 이미지 파일에서 얼굴 기준점을 찾고, 전통 관상학의 삼정(상정·중정·하정) 구분을 참고해 각 구간의 상대 비율을 보여주는 작은 웹 앱입니다.

## GitHub Pages 배포

이 웹앱은 Python 서버 없이 정적으로 실행됩니다. 이 `face` 폴더 안의 파일과 `.github` 폴더를 GitHub 저장소의 루트에 올리면, `main` 또는 `master` 브랜치에 push할 때 Actions가 `index.html`과 `app.js`만 GitHub Pages로 배포합니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하세요. 첫 배포가 끝나면 `https://<사용자명>.github.io/<저장소명>/`에서 HTTPS로 접속할 수 있습니다.

현재 VS Code workspace 루트는 여러 프로젝트를 포함하므로 그 전체를 웹 배포 저장소로 올릴 필요가 없습니다. GitHub 저장소는 `py311/face` 프로젝트 폴더를 루트로 삼아 구성하세요. workflow는 Python 파일을 사이트에 공개하지 않습니다.

카메라 사용은 HTTPS 또는 localhost에서 브라우저 권한이 필요합니다. 권한을 허용할 수 없는 경우 사진 파일을 선택할 수 있습니다.

첫 분석 시 MediaPipe JavaScript/WASM과 얼굴 랜드마크 모델을 CDN에서 불러오므로 인터넷 연결이 필요합니다. 사진 자체는 브라우저 안에서만 처리되며 CDN이나 웹 서버로 업로드되지 않습니다. GitHub Pages에 올리는 파일 중 Python 파일은 웹앱 실행에 사용하지 않습니다.

## 로컬 미리보기

Python 설치가 이미 있다면 앱 폴더에서 정적 파일 서버만 실행할 수 있습니다. 분석은 Python이 아니라 브라우저에서 수행됩니다.

```powershell
python face.py --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. Python 분석 모듈의 회귀 테스트를 실행하려면 `python -m pip install -r requirements.txt`를 먼저 실행한 뒤 테스트 명령을 사용합니다.

## 측정과 해석

MediaPipe Face Mesh 기준점으로 얼굴 기울기를 보정하고, 상정(이마 끝선 추정점~눈썹선), 중정(눈썹선~코끝), 하정(코끝~턱끝)의 세 구간 길이를 전체 길이에 대한 백분율로 계산합니다. 이 앱은 이 경계 조합을 측정 기준으로 채택합니다. MediaPipe의 이마 상단 기준점은 실제 헤어라인을 검출하지 못하므로 근사치입니다.

《신상전편(神相全編)》 「면삼정(面三停)」 계열의 고전 해석은 상·중·하정을 초·중·노년의 흐름과 연결하며, 삼정의 균형을 길상으로 풀이합니다. 문헌과 후대 전승에는 경계 표현 차이가 있어 하정의 시작을 인중으로 설명하는 자료도 있습니다. 이 앱은 그중 코끝을 경계로 삼는 방식을 명시적으로 사용합니다. 화면의 4%p 균형 허용오차는 자동 비교를 위한 앱 자체 기준이며 고전 원문에 나온 수치가 아닙니다.

이 해석은 역사적 관상 체계의 소개이며 개인의 실제 운명을 판단하지 않습니다. 얼굴 비율로 성격, 능력, 건강 또는 운명을 판단할 과학적 근거는 없습니다.

사진은 브라우저 메모리에서만 처리하며 파일로 저장하거나 외부 서버로 보내지 않습니다. 분석 속도를 위해 입력 이미지는 최대 1280px로 축소하며, 20MP 또는 한 변 5000px가 넘는 이미지는 거부합니다.
